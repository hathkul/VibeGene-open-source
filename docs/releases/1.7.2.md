# VibeGene 1.7.2

## New features and improvements

- **More informative translations:** Translation tiles show strand direction on interaction. Hover over an amino acid to highlight its codon and see the full amino acid name; overlapping translations are easier to inspect.
- **Select DNA between features:** Select two features on the map or sequence to highlight the continuous DNA region spanning them. Selected feature frames and labels are easier to distinguish.
- **Clearer feature details:** Feature qualifiers appear on separate lines, with clearer sizes and strand directions and copyable note values. Feature location editing now validates ranges and includes a protection control.
- **Enzyme inspection and sets:** Hover over enzyme labels to see their properties and highlight matching sites on the map. Recognition diagrams and cut markers are clearer, and a built-in Type IIS enzyme set is available.
- **More accurate cloning previews:** Cloning previews now show staggered ends more clearly, with fixes to sticky-end strand bases and TA cloning. Restriction cloning uses the active enzyme sets for the plasmid and insert.
- **Open Database files in a new window:** The standalone app can open files from Database directly in a new window.
