# VibeGene 1.7.3

## New features and improvements

- **More accurate trace alignments:** Large deletions are better represented in sequencing trace alignments, with improved chromatogram display around gaps and on reverse strands.
- **Sequencing traces preserved:** SnapGene trace visibility is preserved, and sequencing traces are retained in cloning history and when cloning between windows.
- **Richer feature notes and qualifiers:** Format feature notes and qualifier values, edit repeated qualifiers separately, and insert symbols from the new symbol picker.
- **Clearer enzyme cut sites:** Restriction cuts beyond the ends of linear sequences and negative coordinates are handled more accurately. Enzyme hints are better positioned on screen.
- **Document names in window titles:** The current document filename appears in the workspace window title, making open windows easier to identify.
