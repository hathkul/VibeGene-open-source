# VibeGene 1.7.1

## Requested by users

- **Protein sequences in dark theme:** Fixed amino acid text contrast, including residues with custom colors.
- **Reworked Enzymes pane:** Search enzymes by name or recognition sequence, add enzymes from a searchable catalog, and show or hide individual enzymes on the map and sequence. Select multiple rows for bulk visibility actions, view noncutters, and save custom enzyme sets. Controls remain visible while scrolling.
- **Linux standalone apps:** AppImage and Debian packages are now available for both AMD64 and ARM64.
- **Windows Ctrl+R shortcut:** Fixed Ctrl+R so it correctly opens **Add Primer** in the Windows standalone app.

## New features and improvements

- **CRISPR region excision:** Remove DNA between two mapped guide targets, including regions spanning the origin of circular DNA. Preview Cas12a staggered ends and simulate compatible junctions with adjustable end filling.
- **Clearer CRISPR cut sites:** Added nominal cleavage markers, illustrative Cas12a strand cuts, and better-positioned cut-detail popovers.
- **Improved circular maps:** Adjust the spacing between enzyme/primer labels and their connector lines. Fixed feature-label placement after recentering and preserved feature callouts when enzyme labels are hidden.
- **Better SnapGene compatibility:** Improved reading and writing of custom enzyme sets and enzyme visibility settings.
- **More convenient Save As:** The dialog now defaults to the opened file’s name and folder.
- **Native Windows color picker:** Feature colors now use the system color picker in the Windows standalone app.
- **Join the community:** The Help menu now includes a link to the VibeGene Telegram group for questions, feedback, and discussion.

## Downloads

- macOS Apple silicon: `VibeGene_1.7.1_aarch64.dmg`
- Linux AMD64: `VibeGene_1.7.1_amd64.AppImage` or `VibeGene_1.7.1_amd64.deb`
- Linux ARM64: `VibeGene_1.7.1_aarch64.AppImage` or `VibeGene_1.7.1_arm64.deb`

Windows-specific fixes are included in this source release. Windows installers remain at the separately published 1.7.0 build.
