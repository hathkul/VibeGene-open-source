# VibeGene 1.6.3 macOS close and mapped-folder verification

The macOS close and mapped-folder workflow was checked with synthetic files. The observed checks covered importing, editing, saving and renaming a mapped sequence, closing and reopening windows, and reconciling an externally modified file.

## Corrected causes

- Native window hide and close events needed explicit permissions and targets.
- Close handlers needed to preserve retained windows and complete reconciliation.
- Retained components needed their busy and closing state reset.
- Mirror scans and rename cleanup needed safer handling of mapped files.

## Automated verification

The JavaScript suite, production build, architecture and type checks, lint baseline, theme checks, and Rust lifecycle tests passed for the tested source. Native UI behavior was also checked in a packaged application. These observations do not cover every possible macOS or filesystem failure.
